# Зображення для проєктів

Сюди ви можете зберігати скріншоти та фотографії ваших робіт (наприклад: `salon.jpg`, `shop.png`, `landing.webp`).

Щоб використати зображення у проєкті:
1. Покладіть файл сюди, наприклад `my-site.jpg`
2. У файлі `js/projects.js` вкажіть:
   ```javascript
   image: "img/projects/my-site.jpg"
   ```
Або ви можете вказати будь-яке пряме посилання з інтернету (URL).
